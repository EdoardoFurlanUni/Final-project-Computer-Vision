Along with the C++ code we provide a CMakeFiles.txt file that can be used to create the “main" executable. 
The program can be used to test images or videos, by providing in the command line the desired file: images, video1 or video2. If the input is wrong, a message will explain the correct use of the executable.
Note that the folder “results" already contains images and videos as output of the code: running again the executable will overwrite these files and will print on the terminal the results that can be seen in the following paragraphs.
